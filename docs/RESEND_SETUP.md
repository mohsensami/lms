# راه‌اندازی ایمیل با Resend

سایت در این سه موقعیت ایمیل می‌فرستد (هر کدام را می‌توانید در **تنظیمات ← ایمیل‌ها** خاموش یا متنش را عوض کنید):

| رویداد | گیرنده | محتوا |
|---|---|---|
| ثبت‌نام (با ایمیل/رمز یا اولین ورود با گوگل) | دانشجو | خوش‌آمدگویی + دکمه‌ی مشاهده دوره‌ها |
| ارسال پیام در «تماس با ما» | فرستنده (و اختیاری: مدیر) | تأیید دریافت + نسخه‌ی پیام (برای مدیر: خودِ پیام و پاسخ مستقیم) |
| پاسخ به دیدگاه (دوره یا مقاله) | صاحب دیدگاه | دیدگاه شما + پاسخ + لینک |
| تیکت (ثبت، پاسخ پشتیبانی، بسته‌شدن) | دانشجو (و اختیاری: مدیر) | شماره، موضوع، اولویت و متن پاسخ + لینک تیکت |
| خرید دوره | دانشجو (و مدرس) | فاکتور (مبلغ، روش پرداخت، کد پیگیری، تاریخ) + لینک ورود + **لینک تک‌تک درس‌های دوره** |

اگر کلید Resend تنظیم نباشد، سایت **به‌هیچ‌وجه خراب نمی‌شود**: ثبت‌نام، خرید و پیام‌های تماس کار می‌کنند و فقط ایمیلی ارسال نمی‌شود (در لاگ سرور هشدار ثبت می‌شود).

## مرحله ۱ — حساب و کلید API
1. در https://resend.com ثبت‌نام کنید.
2. منوی **API Keys ← Create API Key** (دسترسی `Sending access` کافی است).
3. کلید (`re_...`) را فقط یک‌بار نشان می‌دهد؛ کپی کنید و در `.env` بگذارید:
   ```
   RESEND_API_KEY=re_xxxxxxxxxxxx
   ```

## مرحله ۲ — تأیید دامنه‌ی ezylearn.ir (برای ارسال به همه)
بدون تأیید دامنه، Resend فقط اجازه می‌دهد با `onboarding@resend.dev` و فقط به ایمیل خودِ شما ارسال کنید.
1. **Domains ← Add Domain** ← `ezylearn.ir` را وارد کنید (ناحیه‌ی ارسال را نزدیک‌ترین گزینه بگذارید).
2. Resend چند رکورد DNS نشان می‌دهد (معمولاً SPF/MX از نوع TXT/MX و DKIM از نوع TXT یا CNAME). همه را دقیقاً همان‌طور که نوشته در پنل DNS دامنه (nic.ir یا ثبت‌کننده/هاست) بسازید.
3. بعد از چند دقیقه تا چند ساعت **Verify** را بزنید تا وضعیت `Verified` شود.
4. فرستنده را در `.env` بگذارید (آدرس باید روی همین دامنه باشد):
   ```
   EMAIL_FROM="ایزی‌لرن <support@ezylearn.ir>"
   ```

## مرحله ۳ — اختیاری
```
EMAIL_REPLY_TO=support@ezylearn.ir      # پاسخ دانشجوها به کجا برود
ADMIN_NOTIFY_EMAIL=you@example.com     # اعلان پیام‌های تماس (یا در تنظیمات ← ایمیل‌ها وارد کنید)
```

## مرحله ۴ — آزمایش
1. کلیدها را روی هاست هم بگذارید و دوباره Deploy کنید.
2. **حساب ← تنظیمات ← ایمیل‌ها**: وضعیت `RESEND_API_KEY` و `EMAIL_FROM` را ببینید، ایمیل خودتان را بنویسید و «ارسال ایمیل آزمایشی» را بزنید. اگر خطایی از Resend بیاید (مثلاً «domain is not verified») همان‌جا نمایش داده می‌شود.

## پیام‌های تماس در داشبورد
منوی مدیر ← **پیام‌ها**: لیست پیام‌ها (خوانده‌نشده‌ها پررنگ با شمارنده در منو)، باز کردن و خواندن، «پاسخ با ایمیل»، علامت‌گذاری خوانده/خوانده‌نشده، حذف تکی و حذف همه‌ی خوانده‌شده‌ها.
بعد از دریافت فایل پروژه یک بار `npx prisma db push` را بزنید تا جدول پیام‌ها ساخته شود.

## نکته‌ی امنیتی
لینک درس‌ها در ایمیل به صفحه‌ی دوره می‌روند و فقط بعد از ورود با حساب خریدار باز می‌شوند؛ لینک مستقیم فایل ویدیو در ایمیل قرار نمی‌گیرد.

## کلیدهای خاموش/روشن کنار هر بخش
علاوه بر تنظیمات ← ایمیل‌ها، یک کلید فعال/غیرفعال دقیقاً کنار خود بخش هم هست:
- **پیام‌ها**: ایمیل تأیید به فرستنده‌ی پیام و اعلان به مدیر
- **دیدگاه‌ها**: ایمیل پاسخ به دیدگاه
- **تیکت‌ها**: ایمیل تیکت برای دانشجو و اعلان به مدیر

بعد از تغییر پروژه یک بار `npx prisma db push` بزنید (جدول‌های پیام‌ها و تیکت‌ها).
